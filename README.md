# Slide-a-Lama

Browser remake of the classic ICQ-style Slide-a-Lama game.

## Online 1v1
1. Open the site.
2. Player 1 clicks **Создать комнату** and sends the room code.
3. Player 2 enters the code and clicks **Войти**.
4. The game synchronizes directly between browsers using WebRTC via PeerJS.

The project is a fan-made recreation using original code and emoji-based pieces, without the original ICQ game assets.

## GitHub Pages
The repository includes a GitHub Actions workflow for automatic Pages deployment.
